# Sentinel — File Integrity Monitoring and Recovery

Sentinel is a file integrity monitoring and recovery application. It helps users fingerprint important files, monitor them for changes, review file activity, and restore verified backups.

## Features

- File integrity monitoring and change detection
- File fingerprinting and verification
- Backup management and recovery
- Activity and event logs
- Monitoring dashboard
- Settings and configuration

## Requirements

- Node.js (LTS recommended)
- npm or Bun

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in your terminal.

## Production build

```bash
npm run build
npm run preview
```
